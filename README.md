# How to Highlight Line Color While Saving Data as Stream in WPF EditControl
This repository provides a detailed example of how to **highlight line color** while saving data as a stream in the **WPF EditControl**, which is part of the Syncfusion WPF suite. The EditControl is a powerful text editor that supports syntax highlighting, code editing, and advanced customization features. In certain scenarios, you may want to preserve line-specific formatting, such as custom colors, when saving the content to a stream for storage or further processing.

By default, EditControl allows you to apply styles and colors to text lines, but saving these visual attributes along with the text requires additional steps. This sample demonstrates how to capture and maintain line color information during the save operation. You will learn how to use the control’s APIs to retrieve line formatting details, serialize them, and ensure that the highlighted colors are retained when the data is reloaded from the stream.
